A tiny chess engine in 4 KB of Python: bitboard move generation, alpha-beta search with transposition table, quiescence, late-move reductions, killer/history ordering, tapered material + piece-square evaluation, and king-safety (pawn shelter + castling). Talks to the make.fun environment over HTTP.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
